# Reality data layer

This directory contains factual starting-world data. It is not player history and it is not procedural future content.

Rules:

1. Store a source and reference date for factual datasets.
2. Never relabel older statistics as current.
3. Controversial claims must be represented through the sourced claim model rather than as unqualified facts.
4. Real-world updates never overwrite an already-diverged player timeline.
5. Election baselines should prefer Election Commission of India records.

Initial geography sources are Ministry of Home Affairs pages listing India's states and Union Territories.

The next ingestion target is the 2024 Lok Sabha constituency/result baseline from Election Commission of India records.
