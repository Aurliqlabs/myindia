# REPUBLIC: 543

Playable V0.2 browser prototype for the political life simulation.

## Run

Open `index.html` directly in a browser. No installation is required.

## Current gameplay

- New career + player identity
- Starting trait selection
- Scripted prologue
- Jantar Mantar handoff into player control
- Movement funds, volunteers, support, credibility, legal risk, media heat
- Player energy, stress, recognition and progression
- Daily decisions with consequences
- Transparent small-donor fundraising
- Staff/inner-circle foundation
- Local save/continue
- Responsive Paper/Crimson game UI

Real-world political content will be added only through sourced records. Current event cards in this prototype are deliberately simulated while systems are being built.
